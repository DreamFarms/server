### Server 역할
- 배포 DB의 잦은 중단 및 서비스 불가 상태를 해결하기 위해 자동 복구 스크립트 및 자동 백업 스크립트를 구현하여 평균 복구 시간 30분 단축 및 수동 개입 시간 90% 이상 감소
- 미니게임 종료 시 리워드 저장 통신 코드 구현
- 레시피와 보유 재료 비교 후 제작 가능 여부 판단 코드 구현
- 유저의 빵 판매 후 재고 관리 및 빵 개수 업데이트 코드 구현

# 💡 프로젝트 소개

**미니게임을 통해 재료를 얻고 빵을 만들어 판매하며, 수익을 통해 가게를 운영하고 확장하는 경영 시뮬레이션 모바일 게임입니다.**

<br/>

# :scroll: 핵심 기능
- 카페 운영
- 각 미니게임 별 여러 재료 수집
- 보유한 재료로 원하는 빵 제작
- 직접 재료를 넣어 레시피 찾기
